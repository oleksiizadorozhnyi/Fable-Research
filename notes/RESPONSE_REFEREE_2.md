# Response to the second referee report (major revision), 2026-10-13

We thank the referee for the audit; every confirmed finding was reproduced on our side and fixed at the root. The
revised manuscript is generated from one uninterrupted execution of `code/run_all_par.sh` (see "clean run" below).

## Critical 1 — archived EUV cutoff certificate not positive semidefinite (λ_min ≈ −2.4e-17)
Confirmed. The exact verifier (exp21) bisected the scale κ at 50 digits but archived `float(κ)`, which can round up.
Fix (`code/exact_verify.py::verify_scale`): the archived κ is now the largest double not exceeding the verified value,
and that double is itself re-verified (50-digit Cholesky with margin 1e-30) before being saved; the manuscript states
this. All archives in `results/certs/` are regenerated by exp21 in the final run, so every archived certificate is
exactly the verified one.

## Critical 2 — rigorization could return 1 when the true optimum is 0.5 (near-null-space projection)
Confirmed; the projection treated eigenvalues ≤ 1e-12·‖S_D‖ as an exact null space. Fix: `rigorize_certificate` v4
applies no projection; the margin is relative to the summands, λ_min(S_D − κS_B) ≥ 1e-10(‖S_D‖ + κ‖S_B‖), on the full
space; if S_D is singular the bound is 0 (vacuous but valid). A regression test with the referee's structure
(S_D = diag(1, 1e-13), S_B = diag(1, 2e-13)) asserts the bound ≤ 0.5. The exact 50-digit rebuild remains the actual
certificate check; dead orders are dropped from K, so no reported instance relied on the projection, but the routine
was unsound and is replaced. §5 of the manuscript describes v4.

## High 3 — Table 5 used raw solver objectives as certified lower bounds
Confirmed. exp3 now rigorizes all three bounds: the Fourier PSM certificate (v4), the pixel-domain PSM certificate
(verified in the Fourier basis, which is exact because the pixel map preserves Hermitian symmetry), and the DNN
certificate (dual (μ, λ, N≥0): Z = Σμ Q^pix_d − κ Σλ Q^pix_b − N ⪰ 0 certifies the bound over every PSD, entrywise-
nonnegative lifted variable; κ by bisection). exp22 rebuilds all three in 50-digit arithmetic and factorizes them with
margin 1e-30, asserts L ≤ U for both brackets, and the number generator refuses to run if any bracket or exact check
fails. The captions name the quantities as exactly verified certificates.

## High 4 — nonnegative-mask comparison: no pixel integration, three grid spacings
Confirmed. exp3/exp22 now use the pixel-integrated map of Lemma 8 (sinc and half-pixel phase) with N = L/5 pixels
(120, 100, 72 for the 600, 500, 360 nm cells), i.e. a true common 5 nm grid; the feasible nonnegative masks U_+ use the
same map, so they are genuine piecewise-constant nonnegative masks. Text and captions state the pixel counts.

## High 5 — branch-and-bound random instances at 10 nm tolerance versus 5 nm in the random study
Confirmed (a stale tolerance in exp14). The four random instances are now built exactly as in exp2 (τ = 5 nm,
spacing 5 nm); Table 4 and Figure 5 are regenerated from the new run.

## High 6 — clean-run claim versus rerun logs; verification coverage; saved primal artifacts
(a) The final reproduction is a single uninterrupted execution of `run_all_par.sh` with no manual reruns; the log
