# Certified bounds for partially coherent mask synthesis (lithography × convex optimization)

Autonomous research package (2026-10-09 … 2026-10-12). Reproducible with Python ≥ 3.11, numpy, scipy,
cvxpy (CLARABEL, SCS), matplotlib, mpmath; the manuscript needs pdflatex + bibtex (texlive-latex-extra).

```
pip install numpy scipy cvxpy matplotlib mpmath
cd code
python3 -W ignore test_certlitho.py   # 15 unit/regression tests (~5 min)
./run_all_par.sh                      # clean reproduction: 21 experiment scripts in 4 parallel groups (~8 h on 4 cores,
                                      #   16 GB RAM), then exp15/exp21/exp22 (verification, exact 50-digit rebuild, brackets), assemble.py, all figures.
                                      #   Writes results/logs/run_all.log; ends with "=== ALL DONE" or "=== DONE WITH FAILURES".
python3 assemble.py                   # -> results/RESULTS_TABLES.md
python3 make_numbers.py               # -> paper/numbers.tex (all numeric macros) and paper/tab_*.tex (all table bodies)
cd ../paper && pdflatex main && bibtex main && pdflatex main && pdflatex main
```

Layout
- `code/certlitho.py` — model (Abbe/Hopkins, scalar and vector, periodic, diffraction-order domain; 2D source quadratures;
  immersion defocus; Zernike aberrations), SDP relaxations (real/complex/pixel/DNN/SMO), dual certificates + rigorization
  (v3: strict margin on the complement of the common null space), rounding, local solvers, optimal-face exploration, Lasserre-2.
- `code/bnb_cert.py` — interval branch-and-bound lower bound on the single-mask optimum (Theorem 9).
- `code/bnb_sdp.py` — SDP-bounded branch-and-bound with verified dual certificates per node.
- `code/pipeline.py` — end-to-end analysis, DUV/EUV constants and the illuminator catalogue; `code/exp*.py` — experiments;
  `code/figs.py`, `fig2d.py`, `fig5.py`, `fig6.py` — figures; `code/make_numbers.py` — manuscript numbers and tables.
- `notes/` — RESEARCH_STATE.md (persistent state + bug log), PHASE2_DIRECTIONS.md (five directions & scoring),
  THEORY.md (definitions, theorems, proofs), NOVELTY.md, ADVERSARIAL.md, PAPER_v2.md (Markdown manuscript), FINAL_REPORT.md,
  review_*.md (independent adversarial reviews: mathematics, numbers, physics, prior art, editing, code).
- `results/` — JSON outputs, RESULTS_TABLES.md, figs/, logs/.

## Manuscript
`paper/main.tex` (macro-driven: every number comes from `paper/numbers.tex` and every table body from `paper/tab_*.tex`,
both generated by `code/make_numbers.py`; no number is typed by hand) + `paper/refs.bib`; compiled PDF: `paper/main.pdf`.
`paper/main_edit.tex` is the editor-reviewed v2 kept for reference.
